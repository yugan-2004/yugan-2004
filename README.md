| | |
|---|---|
| **Stack** | Python, Streamlit, OpenCV, Tesseract OCR, Pillow, NLTK, Scikit-learn |
| **Scale** | 3 detection modules (image / URL / email) unified into one interface |

**My contribution:** Built all three detection modules end-to-end — OpenCV + Tesseract OCR pipeline for image-based phishing, a URL heuristic risk-scoring engine, and an NLTK-based email classifier — then unified them behind a single Streamlit frontend.
